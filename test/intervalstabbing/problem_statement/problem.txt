Title: Interval Stabbing

Overview
Given n closed intervals on the integer line, choose the fewest integer points so that every interval contains at least one chosen point.

Input
first line: n
next n lines: two integers l r (l ≤ r), the endpoints of a closed interval [l, r]

Constraints
1 ≤ n ≤ 200000
−10^9 ≤ l ≤ r ≤ 10^9

Output
first line: k, the minimum number of points needed
second line: k integers p1 … pk in nondecreasing order, where each pi is an integer
any optimal solution is accepted

Notes
intervals are closed: a point placed at l or r covers [l, r]
multiple optimal solutions may exist; print any one

Examples
example 1
input
3
1 3
2 5
6 7

output
2
3 6

example 2
input
5
0 0
-5 -3
-4 2
2 4
4 4

output
2
0 4

example 3
input
4
1 10
2 9
3 8
4 7

output
1
7
